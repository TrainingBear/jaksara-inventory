Overview
========

jaksara-inventory is a Kotlin-first inventory menu framework for Bukkit/Spigot Minecraft plugins. It exposes a concise Kotlin DSL and Java-friendly overloads to build interactive GUIs composed of ClickableButton instances, paginators, and utility helpers.

Key features
- Kotlin DSL for expressive menu definitions
- Java-friendly API overloads for interoperability
- Click handlers with ExecutionContext (player, inventory click event helpers)
- Paginators for multi-page lists
- Helpers: optionButton, listButton, border and exit templates

Core classes: CustomMenu, InventoryMenuDsl, ClickableButton, ButtonHandler, ExecutionContext, Paginator
