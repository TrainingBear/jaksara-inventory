# Glossary

InventoryMenuDsl — top-level menu builder and inventory holder.
ClickableButton — a button with providers for material/title/lore and a click executor.
ButtonHandler — manages a layout id and pages of buttons.
ExecutionContext — runtime context passed to onClick callbacks.
PlayerData — per-player cache (inventories, chat callback).
Persistent metadata — NamespacedKey data written to item meta to map items to executors.
Paginator — helper to page through lists of elements.
